# 踩坑清单（遇到问题先查这里；同类情况直接遵守，不必重踩）

| 坑 | 正确做法 |
|---|---|
| API Key 明文出现在输出/文档/日志 | 只存本地凭据文件，输出与日志一律掩码（`sk-***`），不写入任何生成物 |
| 识别消息内容块缺 `type` 字段 → 上游报 "Invalid user message" | 图片/视频内容块必须按规范带 `type`：`{"type":"image_url","image_url":{...}}`、`{"type":"video_url","video_url":{...}}` |
| 客户端拦截图片输入（纯文本聊天模型）报"当前模型暂不支持图片" | 输入层拦截发生在技能运行之前：四通道依次尝试——路径/附件/剪贴板提取（桌面端 scripts/clipboard_save.py）/URL 直传，见 references/input.md |
| 视频无法从剪贴板提取 | 剪贴板一般只存位图：视频走 路径/附件/URL 通道 |
| 忽略环境已有模型，重复向用户索要凭据 | 先扫描 Agent 配置与本地配置，已有模型能覆盖的能力优先复用 |
| 模型/接口未确认就"假装接入" | 保持"待配置"状态，如实告知用户 |
| 图片用绝对路径嵌入 → 破图 | 相对路径（`media_out/xxx.png`）或实测可用的 URL/Data URL |
| 大图（>3MB 或宽 >2000px）嵌入破图 | 先缩放 1024 宽预览图再嵌入 |
| `<video>` 标签被客户端过滤 | 用 Markdown 图片语法嵌入视频 |
| moov 在文件末尾 → 卡"加载中" | 必须 faststart 转码 |
| 预览体积上限凭猜测（曾误记 8MB） | 解包客户端源码实测，查找媒体预览大小限制的默认值 |
| 供应商多域名选错 → 下载不到文件 | 用带存储桶的域名，先实测一单再固化 |
| 队列满 / 限流 | 退避重试，不放弃也不暴毙 |
| 下载中断 → 坏文件 | 展示前校验完整性（PIL verify 等） |
| 生成结果与请求不符 | 展示前核对时长/帧率/内容 |
| 接口格式不明 | 向用户索要文档/curl 示例，dry-run 验证后再固化，不猜格式 |
| 返回格式未知（b64/url/自定义） | 打印原始响应，兼容所有分支，未知则报错 |
| 客户端不支持预览 | 如实告知 + 给路径与替代方案，不假装成功 |
| 更换模型后行为异常 | 先确认配置表已更新，再重跑最小实测 |
